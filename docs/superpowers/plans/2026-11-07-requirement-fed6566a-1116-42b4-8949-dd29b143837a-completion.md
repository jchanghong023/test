# 完成报告

## 完成情况

按已批准计划 Task 1 实现单文件 `machine_info.py`，并新增 `tests/test_machine_info.py`（标准库 unittest）。

- 新增 `machine_info.py`：包含 `collect_cpu()`、`collect_memory()`、`collect_disk()`、`collect_os()`、`collect_hostname()`、`collect_arch()`、`format_output(data)`、`main(argv=None)`。
- CPU：Windows 读取注册表 `ProcessorNameString`；Linux 读取 `/proc/cpuinfo` 的 `model name`/`Hardware`；macOS 通过 `sysctl machdep.cpu.brand_string`（仅设计目标，未声明通过）；核心数使用 `os.cpu_count()`。
- 内存：Windows 使用 `ctypes` 调用 `GlobalMemoryStatusEx`；Linux 读取 `/proc/meminfo`；macOS 通过 `sysctl`/`vm_stat`（仅设计目标）。
- 磁盘：使用 `shutil.disk_usage`，路径为当前根路径。
- OS：`platform.system()`/`platform.version()`；主机名 `platform.node()`；架构 `platform.machine()`。
- 所有采集器在失败时回退为 `Unknown`；输出为人类可读分节文本；`main` 拒绝任意参数并返回 2，不抛 traceback。
- 仅 Python 标准库；未修改现有文件。
